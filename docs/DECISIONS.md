# Decisiones
- Adoptamos Godot 4.7.2 .NET portátil al encontrar una distribución estándar sin soporte C# en otro directorio. Editor y plantillas oficiales verificados con los SHA-256 publicados por GitHub, solo dentro de .local. El repositorio contiene archivos fuente y ajustes compartibles.
- Git 2.52 y Git Credential Manager ya tenían acceso a la cuenta. La API REST de GitHub permitió crear el repositorio privado. GitHub CLI no figuraba en el PATH. Git LFS no aportaba valor para este volumen de recursos.
- Mallas originales, geometría determinista, atlas bitmap y síntesis PCM mantienen editable el origen del arte. Python sirve para regenerar recursos. Blender es opcional para incorporar GLB. FFmpeg se usa para material de exhibición cuando está disponible.
- La composición 2D posterior al mundo conserva transparencias, partículas y niebla. El shader estima las familias a partir de color. Un pase de identificación por material introduciría otra representación que sincronizar; conservar como ampliación si los artistas necesitan asignaciones exactas. [Documentación de shaders de pantalla](https://docs.godotengine.org/en/stable/tutorials/shaders/screen-reading_shaders.html)
- Se usaron consola local, Git, API de GitHub, inspección de PNG y documentación del motor. El entorno también ofrecía automatización visual y conectores de documentos y diseño. El juego se puede compilar fuera de Codex.
